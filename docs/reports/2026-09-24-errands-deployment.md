## MySQL 兼容修复

上线前的独立 MySQL 测试发现两个相同根因的问题：并发提交相同售后补偿时重复创建退款记录，以及同一骑手同时接两笔订单时未正确读取最新累计垫款。

原因是 MySQL 默认可重复读与 Prisma 的互斥记录 upsert 配合时，读取快照可能早于等待锁。修复后，代买写事务、代买直接接单和后台代买派单使用 ReadCommitted，等待锁后重新读取已提交状态；创建订单的报价校验保留 Serializable。普通取件、寄件等业务的隔离级别不变。

修复已同步回本地后端源文件，发布产物与最终代码的校验和一致。
