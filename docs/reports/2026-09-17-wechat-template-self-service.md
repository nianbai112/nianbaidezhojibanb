# 服务号模板后台自助配置修复

2026-09-17 20:34（Asia/Shanghai）已部署。

## 问题及行为

原通知后台将模板标记为系统托管，只展示状态，API 拒绝修改内置模板的 ID 和字段，发送程序还会使用内置字段覆盖数据库配置。超级管理员也无法完成自助接入。

现服务号与小程序模板卡片均提供「配置模板」。有 system:config 权限的运营人员及超级管理员可保存模板 ID、字段对应关系和模板启停状态；可以修改全局模板或已有校区模板，修改不改变所属场景、渠道或校区。发送程序采用保存的字段，配置查询也如实返回数据库记录。

服务号模板支持「读取微信字段」：输入完整模板 ID 后读取本账号已添加的模板，自动匹配中文业务字段，无法识别的字段留待人工选择。读取接口执行相同权限检查，不返回凭据和 access_token。

表单及接口校验完整模板 ID、字段、重复配置与新单必需五项内容；同一个全局配置并发首次保存使用确定 ID 防止 MySQL NULL 唯一约束产生重复行。保存模板不修改通知场景开关，也不发送测试消息。
