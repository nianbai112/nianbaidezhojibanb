## Nginx 兼容修复

线上通用 `/api/` 规则会去掉前缀，但朋友圈回调和原始请求体解析器挂载在 `/api/wechat-moments/webhook`，导致本机返回 400、公网返回 404。

为 `/api/wechat-moments/webhook` 添加精确匹配，完整转发原始路径。修改前保存 `nginx-before.conf`，修改后 `nginx -t` 通过并平滑 reload。公网无签名回调返回 400，随后再次执行全部只读接口和资源检查。相同规则已补入本地 `deploy/nginx/portal-site.conf.sample` 与 `admin-site.conf.sample`，便于后续部署沿用。
