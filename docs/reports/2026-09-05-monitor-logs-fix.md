本地数据库的完整日志读取正常，故“完整字段读取导致线上 500”仅是需要现场诊断排除的方向，不是已经证实的根因。已新增只读诊断脚本：

```sh

```

该脚本读取完整字段/列表字段查询结果、近期监控接口异常堆栈、微信按渠道/通知类型/状态/错误码的统计，不执行重试、不发送通知、不改数据库。应在发生问题的实际后端环境运行。

截图可确认的失败分类：

| 情况 | 当前处理 |
| --- | --- |
| 公众号 40165 / invalid weapp pagepath | 显示小程序页面无效及核对建议；发送入口校验路径格式和应用编号配置，不再静默丢掉跳转信息。需要继续核对正式版页面与账号关联。 |

历史失败记录不改写存储状态；读取时可识别未授权、缺模板等历史未发送情况。前台统计明确为本页统计，不冒充全量失败率。后台任务没有 HTTP 请求 IP 时显示系统任务；不会将服务器 IP 写成接收用户 IP，也不会补造历史来源。

重试改为真实重新发送语义，前台有提交锁和中文提示。后端拒绝把未转换的业务数据直接当微信模板重试。公众号受理后继续等待回执，不能把受理当成最终送达；接口响应缺少错误码也不再判成功。
