## 发现并修复的问题

原 `TransformInterceptor` 对校园地图根路径返回 `HTTP 200 + { code: 0, data: ... }`。新 Go 代码先前只将包裹响应的 `code: 200` 识别为成功，因此真实 Node 地图正常时，Go 就绪检查和学生读取仍返回 503。

这是新 Go 适配层缺陷，不是运营路线审核失败或原地图数据损坏。之前模拟测试的数据形状没有覆盖真实拦截器，导致漏检。

修复仅限 Go 适配：识别数字成功码 0 和 200，地图响应保留原成功码；拒绝错误码、字符串码、null 和缺失成功码。身份校验也使用相同严格成功判断，不绕过 JWT、账号状态或服务密钥。

真实 Nest 联调先复现为 4 项失败、1 项通过，修复后原 5 项全部通过；随后补充真实 Nginx 入口测试，最终 7 项全部通过。
