## 进程级测试实际验证内容

脚本：[process-smoke.test.cjs](../../services/campus-map-read/process-smoke.test.cjs)。

1. 旧 HTTP 上游与 Go 的地图 `data` 内容一致，只多 `readRevision`。
2. 16 个请求工作循环合计发送 512 次受保护读取，全部成功；模拟上游收到 512 次访问校验，在这一短批次内收到 0 次后台地图同步请求。说明没有每次访客读取都查询地图；**不代表 512 人同时在线，更不是线上容量结论**。
3. 缺失登录令牌被拒绝；模拟账号撤销后携带旧 ETag 也无法读取缓存。
4. 正式版本仍为 v16 时撤回北门，内容摘要改变，Go 同步后的结果不再包含北门。
5. 模拟上游返回 503 时，受保护读取立即失败，公开数据在原租期结束后停止返回；上游恢复后读取恢复。
6. Go 优雅退出后，原模拟上游仍响应；重新启动时若上游不可用，不会恢复未经新鲜性确认的旧地图。
7. 写请求、内部导出路径、未知学校和重复学校参数被拒绝；进程输出不包含测试服务凭据或用户令牌。
