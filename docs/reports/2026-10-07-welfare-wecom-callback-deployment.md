## 问题与修复

- 原后台通过以 `/` 开头的路径创建 URL，丢失 API 基地址的 `/api` 前缀。线上访问 `/wechat/wecom/callback` 被官网 SPA 接收，返回 HTML，无法完成企业微信的加密挑战验证。
- 后台改用 Axios 的 `getUri` 按实际 API 基地址生成回调 URL，默认显示 `https://yuntingzhe.cn/api/wechat/wecom/callback`；配置提示对应企业微信自建应用的“设置API接收”。
- Nginx 增加精确匹配 `/wechat/wecom/callback` 的后端转发，保留查询参数和请求体。用户之前填写的旧地址可以继续接收验证及事件，无需跳转。
- 仅替换 `admin/src/views/marketing/WelfareWecomPanel.vue`、管理后台构建产物，以及 `/etc/nginx/sites-enabled/lingmeng.conf`。构建基于服务器当前后台源码快照，仅覆盖该组件；依赖清单与本地验证环境一致。
